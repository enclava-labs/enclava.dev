# Enclava.dev — Confidential Applications Platform

> Push a container. Get a confidential application. Encrypted in use, verifiable by anyone, invisible to the cloud.

Enclava.dev is a confidential applications platform from [Enclava Labs](https://enclava-labs.com/). You bring a Linux container; we run it inside a hardware trusted execution environment (currently AMD SEV-SNP). Secrets are delivered into the TEE. Operators cannot read your process memory, filesystem, or traffic.

## Two ways in

- **Hosted platform (invite beta).** Request access, then deploy with the `enclava` CLI. TLS, encrypted volumes, and public attestation per deploy.
- **Self-host the engine.** The control plane ([CAP](https://github.com/enclava-labs/cap)) is open source (MIT). Run it on your own SEV-SNP hardware.

## What you can run

Any Linux container: web apps, databases, inference servers, internal tools, secret-bearing workers. The platform is not limited to AI.

Confidential AI products live at [enclava.ai](https://enclava.ai).
